**Objetivo de sesión** (imagen decorativa: dos personas revisando documentos, con overlay azul)

- Entender y analizar que en las empresas productivas, existen situaciones en las que de un solo proceso de fabricación surgen dos o más productos diferentes.

- Determinar métodos de asignación de costos entre productos conexos.
- Determinar costos unitarios de dichos productos para medir el nivel de ingreso que generan.

## Slide 3

**Costo de productos conjuntos**

- Son Productos Individuales
- Tienen Precios de Venta significativos
- Se generan de manera Simultanea a partir de la misma Materia Prima y/o el Mismo Proceso de Producción
- Con un mismo proceso de producción se logran varios productos
- Los Costos Conjuntos son Indivisible
- Tienen siempre un Punto de Separación
- Ninguno de los Productos Conjuntos es significativamente Mayor en Valor que los demás.

## Slide 5

**Métodos de costos conjuntos** (imagen decorativa: científica de laboratorio con guantes azules sosteniendo tubos de ensayo)

- 1º Método Costo Medio
- 2º Método Valor de Venta Punto de Separación
- 3º Método Valor Realizable Neto

- El objetivo es separar los costos conjuntos y lograr asignar un costo a cada producto obtenido (Ccasig)
- Se entiende que el Costo de Producción de cada producto, se obtiene Sumando al Costo Conjunto Asignado (Ccasig) el Valor del Costo Adicional (Ca)
- El Ca es el Costo de la Operación Adicional requerida para obtener el Producto Conjunto
- Fórmula: **CP = CCasig + Ca**

## Slide 12

**1. Método costo medio (Cm) de las Unidades Producidas**

1. Cálculo del Cm: Se determina el Costo Conjunto Unitario, dividiendo el Costo Conjunto (CC), entre las unidades producidas en total. Cm = CC/(Pa+Pb) = 150,000/1,500 = S/.100

2. Costo Conjunto Asignado (CC asig): El Costo Conjunto asignado a cada producto se obtendrá multiplicando ese costo unitario Cm por las unidades producidas de cada producto.
   - CasigB = Cm.Pa = 100 × 1,000 = 100,000
   - CasigA = Cm.Pb = 100 × 500 = 50,000

3. Costo de Producción (CP): Cpa = 50,000 + 10,000 = 60,000; CPb = 100,000 + 20,000 = 120,000

Imagen decorativa: ilustración de línea de embotellado industrial.

## Slide 13

**2. Valor de Venta de Mercado en el Punto de Separación**

1. Cálculo del Valor de Venta Total (VV t): En este caso se determina el Valor de Venta Total de el total de lo producido.
   VV total = Suma (precio × producción) = 500×150 + 1,000×200 = 275,000

2. Cálculo de la Tasa de Asignación (T asig): T asig = VV producto / VV total
   - T asig A = 75,000 / 275,000 = 0.272727
   - T asig B = 200,000 / 275,000 = 0.727272

Imagen decorativa: ilustración de línea de embotellado industrial.

## Slide 14

**2. Valor de Venta de Mercado en el Punto de Separación** (continuación)

3. Costo Conjunto Asignado (CC asig): CC asig = T asig × CC
   - Casig a = 0.2727272 × 150,000 = 40,910
   - Casig b = 0.727272 × 150,000 = 109,090

4. Costo de Producción CP: CP = CC asig + Costo Adicional
   - Cpa = 40,910 + 10,000 = 50,910
   - CPb = 109,090 + 20,000 = 129,090

Imagen decorativa: ilustración de línea de embotellado industrial.

## Slide 15

**3. Valor realizable neto (VRN)**

1. Precio de Venta Total VVt: Valorizamos la producción total al precio de venta final. PV t = precio × producción

2. Valor Realizable Neto VRN: VRN = PVt – Costo Adicional y GO. A este valor PVt le restamos a cada producto sus Costos Adicionales con los Gastos de Operación (GO) incluidos después del punto de separación.
   - VRNa = 500×250 – (10,000+2,000) = 113,000
   - VRNb = 1,000×300 – (20,000+5,000) = 275,000
   - Suma VRN = 388,000

Imagen decorativa: ilustración de línea de embotellado industrial.

## Slide 16

**3. Valor realizable neto (VRN)** (continuación)

3. Tasa de Asignación (T asig): T asig = VRN / Suma VRN
   - T asig A = 113,000 / 388,000 = 0.29123
   - T asig B = 275,000 / 388,000 = 0.70877

4. Costo Conjunto Asignado (CC asig): El Costo Conjunto asignado a cada producto se determina con la proporción de sus VRN de cada uno de ellos.
   - Ccasig a = (0.29123) × 150,000 = 43,684
   - Ccasig b = (0.70877) × 150,000 = 106,316

Imagen decorativa: ilustración de línea de embotellado industrial.

## Slide 17

**3. Valor realizable neto (VRN)** (continuación)

5. Costo de Producción: CP = CC asig + Costo Adicional
   - CP a = 43,684 + 10,000 = 53,684
   - CP b = 106,316 + 20,000 = 126,316

6. Costo Total (CT): CT = CP + GO

7. Utilidad Neta (UN): Elaboración del EPG para cada método

7. Rentabilidad (R): R = Utilidad Neta / CT

Imagen decorativa: ilustración de línea de embotellado industrial.

## Slide 22

**1. Método costo medio**

1. Cálculo del Cm: Cm = CC/(Pa+Pb+Pc) = 164,000 / 820,000 = 0.2

2. Costo Conjunto Asignado (CC asig):
   - CCasigB = Cm.Pa = 0.2 × 280,000 = 56,000
   - CCasigA = Cm.Pb = 0.2 × 340,000 = 68,000
   - CC asig = Cm.Pc = 0.2 × 200,000 = 40,000

3. Costo de Producción (CP):
   - Cpa = 56,000 + 50,000 = 106,000
   - CPb = 68,000 + 30,000 = 98,000
   - CPc = 40,000 + 35,000 = 75,000

## Slide 23

**2. Valor de Venta**

1. Cálculo del Valor de Venta Total (VV t): VV total = Suma (VV × producción) = 280,000×0.8 + 340,000×0.7 + 200,000×0.95 = 652,000

2. Cálculo de la Tasa de Asignación (T asig): T asig = VV producto / VV total
   - T asig A = 224,/652, = 0.34356
   - T asig B = 238,/652, = 0.36503
   - T asig C = 190,/652, = 0.29161

## Slide 24

**2. Valor de Venta** (continuación)

3. Costo Conjunto Asignado (CC asig): CC asig = T asig × CC
   - Casig a = 0.34356 × 164,000 = 56,344
   - Casig b = 0.36503 × 164,000 = 59,865
   - Casig c = 0.29164 × 164,000 = 47,791

4. Costo de Producción CP: CP = CC asig + Costo Adicional
   - Cpa = 56,344 + 50,000 = 106,344
   - CPb = 59,865 + 30,000 = 89,865
   - CPc = 47,791 + 35,000 = 82,791

## Slide 25

**3. Valor Realizable Neto (VRN)**

1. Precio de Venta Total VVt: Valorizamos la producción total al precio de venta final. PV t = (precio × producción)

2. Valor Realizable Neto VRN: Para cada producto se calcula: VRN = PVt – Costo Adicional y GO. A este valor PVt le restamos a cada producto sus Costos Adicionales con los Gastos de Operación (GO) incluidos después del punto de separación.
   - VRNa = 1.15×280,000 – (50,000+4,000) = 268,000
   - VRNb = 1.00×340,000 – (30,000+1,000) = 306,000
   - VRNc = 1.40×200,000 – (35,000+5,000) = 240,000
   - Suma VRN = 268,000 + 306,000 + 240,000 = 814,000

## Slide 26

**3. Valor Realizable Neto (VRN)** (continuación)

3. Tasa de Asignación (T asig): T asig = VRN / Suma VRN
   - T asig A = 268,000 / 814,000 = 0.3292384
   - T asig B = 306,000 / 814,000 = 0.3759214
   - T asig C = 240,000 / 814,000 = 0.2948402

4. Costo Conjunto Asignado (CC asig): El Costo Conjunto asignado a cada producto se determina con la tasa de asignación.
   - Ccasig a = 0.3292384 × 164,000 = 53,995
   - Ccasig b = 0.3759214 × 164,000 = 61,651
   - Ccasig c = 0.2948402 × 164,000 = 48,354

## Slide 27

**3. Valor Realizable Neto (VRN)** (continuación)

5. Costo de Producción: CP = CC asig + Costo Adicional
   - CP a = 53,995 + 50,000 = 103,995
   - CP b = 61,651 + 30,000 = 91,651
   - CP c = 48,354 + 35,000 = 83,354

6. Costo Total (CT): CT = CP + GO

7. Utilidad Neta (UN): Elaboración del EPG

7. Rentabilidad (R): R = UN / CT

**Métodos Costeo Subproductos**

**1. Reconocimiento del Subproducto al Momento de la Venta**
En este caso, se considera a las Venta de Subproductos como Ingresos por Ventas, pero de carácter extraordinario. Entonces en ese caso al Elaborar el EPG, aparecen dos tipos de Ingreso:

- A. El Ingreso por Ventas de los Productos Principales
- B. El Ingreso por Ventas Extraordinarias de los Subproductos

**Métodos Costeo Subproductos** (continuación)

Y solo se considera como Costo de Venta, exclusivamente el Costo del Producto Principal. Los Ingresos dependerán del precio de venta pactado.

**2. Reconocimiento del Subproducto al Momento de la Producción**
En este caso, se considera en forma separada al Producto Principal, del Subproducto. En otras palabras se le trata como dos productos diferentes.
