## Slide 5

Título: "Actividad: Roadmap Tecnológico"
Subtítulo: "Roadmap tecnológico responsable: de visión a ejecución"
Frase destacada: "La visión define destino; el roadmap define decisiones, secuencia, riesgos y métricas."

Visual: tabla/diagrama de 6 filas, cada una con una categoría (columna izquierda, con barra de color vertical) y dos columnas de descripción (dimensión y pregunta guía). Reproducida como tabla:

| Categoría | Dimensión | Pregunta guía |
|---|---|---|
| Valor | capacidad de negocio / KPI | ¿Qué resultado medible buscamos? |
| Datos | fuentes / calidad / permisos | ¿Tenemos datos confiables y uso permitido? |
| Tecnología | cloud / modelos / integración | ¿Compramos, potenciamos o construimos? |
| Personas | roles / capacitación / adopción | ¿Quién opera, aprueba y cambia el proceso? |
| Riesgo | controles / auditoría / incidentes | ¿Qué puede fallar y quién responde? |
| Costo | FinOps / deuda técnica / sostenibilidad | ¿Cómo evitamos pilotos caros y deuda oculta? |

Cada fila tiene un color de fondo distinto (azul, lila, ámbar, gris azulado, rojo claro, verde claro) para diferenciar visualmente las 6 dimensiones.

Al pie, recuadro de actividad: "Actividad: Completen el roadmap para un caso de banco o educación con IA y definan qué escalarían a negocio, legal, seguridad y data governance."
